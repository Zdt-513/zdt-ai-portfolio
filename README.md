# 周德涛｜数字作品集

这是一个无需安装依赖的静态作品集。首页用响应鼠标的流动线条开场，滚动后按顺序介绍三个项目；每个项目都可以打开独立说明页。

## 查看

- 在浏览器中打开 `index.html`。
- `aigc/index.html` 是 AIGC 创作台完整案例，包含三张图、制作流程和实际提示词。
- `petmed.html` 与 `bossflow.html` 分别介绍知识问答项目和本地求职工作流。

## 三个项目

1. **AIGC 创作台 / Material · Light**：基于 MIT 许可的 NextChat 二次开发。三张玻璃主题图像由外部 AI 图像工具生成后导入画廊，案例页说明了这一真实过程。
2. **宠医智库 PetMedKB**：宠物医疗知识整理与引用问答的工程演示。案例页加入疾病星空图与问答检索的实际界面截图，并裁去侧栏数量信息。
3. **BossFlow**：基于开源 [BossFlow](https://github.com/chenyu152/BossFlow) 的本地应用实践。作品页使用流程示意图，不含真实岗位或简历数据。

## 视觉参考

参考了 [Awwwards / The AI Gallery](https://www.awwwards.com/sites/the-ai-gallery) 的暗色展陈与亮色强调、[Kaleidoz](https://www.awwwards.com/sites/kaleidoztm-design-website) 的动态空间感，以及 [Sea of Stars](https://github.com/jzmn-crft/sea-of-stars-template) 和 [photo.arden.nl](https://github.com/aderaaij/photo.arden.nl) 的滚动叙事与图像优先呈现。页面与素材为本项目制作，没有复用这些项目的代码或图片。

所有页面、图片和提示词都放在本目录中，保持相对路径，可以离线打开，也可以直接压缩分享。
