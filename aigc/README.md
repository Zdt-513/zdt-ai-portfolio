# Material / Light — AIGC 创作台

## 项目介绍

这是一个个人概念作品：基于 MIT 许可的 NextChat 进行二次开发，将原来的聊天入口改造成图像创作首页、生成面板和作品画廊。项目同时制作了三张 AI 静态图像，用一组统一的视觉规则展示“提示词 → 图像 → 画廊 → 项目案例”的过程。

**查看方式：**双击 `index.html`，即可离线查看完整案例页。三张图片在同一文件夹中。`prompts.md` 保存实际生成提示词和制作记录。

## 视觉规则

- **色彩：**近黑背景负责留白，黄绿色只用于光线与重要信息。
- **材质：**玻璃、石材和混凝土贯穿三张图，统一触觉感受。
- **构图：**每张只保留一个主体；花、瓶、建筑分别构成自然、产品、空间三个尺度。
- **摄影感：**强调暗部层次、真实折射、精确阴影和克制的胶片颗粒。
- **排除项：**不在图像中生成文字、品牌或虚构界面；文字由网页后期排版。

## 制作过程

1. 确定“玻璃与光”的系列概念、色彩和构图约束。
2. 为三个不同主体分别写提示词，保留相同的材质、光线和摄影语言。
3. 使用 Codex 内置图像生成工具生成三张静态图片，逐张检查主体结构和系列一致性。
4. 将图片导入 AIGC 创作台画廊，保留提示词和“AI 生成 · 外部导入”的来源标记。
5. 制作本案例页，解释视觉判断、过程和项目边界。

## 真实边界

图像由 Codex 内置图像工具生成，之后导入创作台。创作台已接入 Stability 和 GPT Image Mini 请求流程，但本地 Stability 缺少密钥，现有 OpenAI API 账户无可用额度；因此这三张图不是在创作台内通过 API 生成。画廊记录保存在本机浏览器中，离线案例页和图片文件是可分享的展示版本。界面由 AI 辅助完成二次开发；不要描述为从零独立开发。
